판정 로직

1계단 출입구 추출 — 2개
계단 실 폴리곤을 1셀 팽창해 바깥 보행격자와 맞닿는 접점(=문 천공부)을 군집화 → 각 군집 중심이 출입구. 도면에 문 기호가 없어도 통행 가능 개구부가 있으면 자동 인식.
2보행 거리장 — 100mm 격자
문 = 통행, 벽·기둥 = 차단으로 래스터화. 모든 출입구에서 8방향 다익스트라 — '각 부분으로부터'를 셀 단위로 계산. 라벨 없는 통로·개방 공간도 자동 포함.
3실별 최원점 판정 — 14실
각 실에서 계단까지 가장 먼 지점의 보행거리로 판정: · ≤ 30m → 적합 (건축법 시행령 §34 원칙) · 30~50m → 확인필요 (주요구조부 내화·불연 완화 검토) · 도달 불가 → 미도달(피난 불능 — 최우선 확인)
4피난 동선 — 경사 하강
각 실 최원점에서 거리장이 줄어드는 방향으로 내려가면 실제 개구부(문)를 지나는 최단 경로가 그려진다. 히트맵: 초록(가까움) → 빨강(30m).

법적 검토 — 결과 대조

확인필요직통계단 보행거리 ≤ 30m
건축법 시행령 제34조 — 체크 11388
조문거실의 각 부분으로부터 계단(직통계단)에 이르는 보행거리가 30미터 이하가 되도록 설치할 것. 주요구조부가 내화구조 또는 불연재료인 건축물은 50미터(16층 이상 공동주택은 40미터) 이하.
결과 비교최악 보행거리 30.8m (전 실 셀 단위 전수) · 30m 초과 실 3곳 내화구조 완화(50m) 적용 가능 여부 확인 필요 — 확인되면 --fire-resist 옵션으로 재판정.
