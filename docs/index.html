법령 DB 규칙×실 매칭(면제 연결로 "어느 의무를 끄는지"까지 추적) + 구역별 최대커버 배치 + 보 살수장애 회피 + 100mm 셀 전수 검수. 확신 낮은 실은 ⚠로 표시되고 사람이 제외/설치를 확정한 결과(출처 '사람')가 반영돼 있습니다. 상단 🏢 버튼으로 판정이 전제한 건물 사실(설계 가정)을 볼 수 있습니다.

🚪 피난 경로 검토 — 보행거리 §34 판정

계단 출입구 자동 추출 → 보행 거리장 → 실별 판정. 한도(원칙 30m / 내화 완화 50m)는 법령 DB에서 규칙 원문째 가져오고, 완화는 건물 사실(내화구조·설계 가정)로 자동 적용됩니다 — 40m(16층 이상 층 전용)를 쓰지 않은 사유까지 리포트에 남습니다.
